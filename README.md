## 🌟 Featured Open-Source Repositories

### ☀️ [oscfit — Coronal Seismology Pipeline](https://github.com/Vibhav-Aggarwal/oscfit)
> *An Automated Bayesian Framework and Seismological Inversion Pipeline for Decayless Kink Oscillations in Solar Coronal Loops*
- Automated sub-pixel slit tracking, wavelet-based oscillation detection, and Bayesian MCMC fitting.
- Direct seismological inversion of local plasma parameters and coronal magnetic field strength ($B$).
- Submitted & in-review at the **Journal of Open Source Software (JOSS)** ([Submission Status](https://joss.theoj.org/papers/84a9ed30d656b021760e68758362501c)).
- **Tech Stack**: Python 3.11+, SunPy, AstroPy, PyMC, NumPy, SciPy, Matplotlib.

### 🌐 [zero-cost-sovereign-computing — Multi-Node Cluster](https://github.com/Vibhav-Aggarwal/zero-cost-sovereign-computing)
> *Reference Configuration for an 11-Node Heterogeneous Sovereign Compute Cluster*
- **Version 2 release**: 11 nodes spanning 5 segments (Cloud · Lab · Office · Home · Nomadic).
- Invoice-verified marginal capital outlay of **₹51,525 (~USD 625)** against historical acquisition cost **≥ USD 13,000**.
- Recurring cloud fees constrained to **≈ ₹300/month (~USD 3.60/month)** across **20+ months** continuous operation.
- Multi-plane routing: mDNS local discovery → Headscale mesh VPN (`100.64.0.0/10`) → Cloudflare Tunnels → MCP federation.
- Companion to publication: [Zenodo 10.5281/zenodo.19654425](https://doi.org/10.5281/zenodo.19654425).

### 🤖 [openclaw — WhatsApp-Native Agentic Orchestration](https://github.com/Vibhav-Aggarwal/openclaw)
> *Agentic LLM Orchestration Architecture for Operational Workflows*
- WhatsApp-native conversational dispatching for asynchronous tasks, inventory, and enterprise systems.
- Robust state machines, tool-calling validation, and sandboxed execution.
- Companion to publication: [Zenodo 10.5281/zenodo.19679449](https://doi.org/10.5281/zenodo.19679449).

### 🔐 Biometrics & Embedded Protocol Research
- **[ebkn-m61-protocol](https://github.com/Vibhav-Aggarwal/ebkn-m61-protocol)**: Reverse-engineered protocol catalog, byte-level packet dissectors, and pure-Python reference listener for EBKN / Realand BioFace M61 biometric access terminals.
- **[zkteco-adms-server](https://github.com/Vibhav-Aggarwal/zkteco-adms-server)**: Standalone Python ADMS push receiver daemon for ZKTeco and eSSL biometric terminals in push mode without proprietary vendor software.
- **[zkteco-pull-toolkit](https://github.com/Vibhav-Aggarwal/zkteco-pull-toolkit)**: Python CLI utilities for ZKTeco Port 4370 Pull protocol: attendance sync, door release, clock sync, and cloud synchronization.
- **[terminal-firmware-atlas](https://github.com/Vibhav-Aggarwal/terminal-firmware-atlas)**: Open hardware identification matrix, OEM taxonomy, and integration decision guide for biometric attendance terminals.
